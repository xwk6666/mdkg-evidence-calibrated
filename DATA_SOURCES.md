# Data sources and third-party boundaries

CrisisMMD v2.0: https://crisisnlp.qcri.org/crisismmd
Terms: https://crisisnlp.qcri.org/terms-of-use.html
The terms distinguish shareable tweet IDs from confidential source contents and
include research-use, deletion and citation conditions. This release does not
presume these terms authorize an unrestricted CC license over the source dataset.
Original posts, images, endpoints and upstream-linkable IDs/split lists are not
distributed. The original source article and dataset should be cited when lawfully
obtaining and using the underlying data; see the official source for its citation.

MASH: https://huggingface.co/datasets/YRC10/MASH
Inspected source revision: 8a4aeaabde0c247b6cd72451c7bd3cdba921884c.
The card labels its release 1.0 and declares CC BY 4.0 for its ID/annotation
release; the linked https://zenodo.org/records/17682231 is labeled v3. These are
distinct version labels. No platform media, hydrated post text or platform IDs
are distributed here. Attribute MASH to its source maintainers and dataset record,
not to this paper's authors. Frozen predictions are this research's outputs, not
a redistribution of the full upstream dataset.

CLIP base: https://huggingface.co/openai/clip-vit-base-patch32
Code license: https://github.com/openai/CLIP/blob/main/LICENSE
NLI: https://huggingface.co/cross-encoder/nli-deberta-v3-base
Base: https://huggingface.co/microsoft/deberta-v3-base
No weights, tokenizers, fitted serialized calibrators or model caches are bundled.
Code licenses do not automatically settle checkpoint or training-data rights.

Only original research labels/numeric outputs and descriptive metadata are offered
under the data license, to the extent the authors have authority to grant it.
No upstream copyright, privacy, personality or platform-content rights are granted.
This file is attribution and an access pointer, not a grant to redistribute originals.
